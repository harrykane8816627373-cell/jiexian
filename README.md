# 解线 · Untangle

一款空间益智小游戏。拖动节点，把虚线理成绿色实线。

[在浏览器里开始玩](https://harrykane8816627373-cell.github.io/jiexian/)

## 玩法

- **随机出题** — 选择简单、中等或困难，节点数可自定为 4–18。模式包括经典、固定点、反向联动、旋转星盘、滑轨、禁行区和混合机制。
- **自定义题** — 在棋盘摆放最多 18 个节点，依次点两个节点连线。可以移动、删除和撤销，也可以直接试玩或求解。求解器会判断图是否能在平面上无交叉展开。高密度自定义图会按解的间距缩小节点。
- **辅助解题与计时** — 提示演示一步，一键求解展示整套动作。首次移动自动开始计时，也可以手动开始、暂停或继续。解开后停表，重开时归零。

拖动空白处移动视图，用滚轮或棋盘上的按钮缩放，按 1 回正。用键盘时，先聚焦棋盘，用 Q / E 选点，按方向键移动，按住 Shift 可以增大步幅。

## 本地运行

直接用现代浏览器打开 `index.html`。项目是原生 HTML、CSS 和 JavaScript，无需安装依赖。当前随机题和自定义题草稿保存在当前浏览器。

`engine.js` 计算节点位置、检测几何冲突并编排求解步骤。`puzzles.js` 生成可解的随机布局，并从 `planarity.js` 取得自定义题的平面嵌入。`game.js` 负责渲染、输入、计时和存档。平面性检测与增广的部分实现改编自 [NetworkX 3.5](https://github.com/networkx/networkx/tree/networkx-3.5)，许可见 [NETWORKX-LICENSE.txt](./NETWORKX-LICENSE.txt)。GitHub Pages 使用 `main` 分支根目录。
