# 解线 · Untangle

一款空间益智小游戏。拖动节点，把虚线理成绿色实线。

[在浏览器里开始玩](https://harrykane8816627373-cell.github.io/jiexian/)

## 玩什么

- **八个关卡**：从自由拖拽开始，逐步解锁玩法的复杂度。固定点保持原位，同字母节点反向联动，R 节点随星盘一起转。
- **滑轨与禁行区**：滑轨节点沿轨道移动。节点和连线都要避开禁行区。
- **每日一结**：北京时间每天 00:00 生成一道可解的新题。同一天的布局一致，可以挑战目标步数。
- **提示和求解**：提示演示一步，一键求解逐步移动节点。两种辅助操作都可撤销。辅助完成和独立通关分别标记。

拖动空白处移动视图，用滚轮或棋盘上的按钮缩放，按 1 回正。用键盘时，先聚焦棋盘，用 Q / E 选点，按方向键移动，按住 Shift 可以增大步幅。

## 本地运行

直接用现代浏览器打开 `index.html`。项目是原生 HTML、CSS 和 JavaScript，无需安装依赖。进度与最佳步数保存在当前浏览器。

`engine.js` 计算节点的位置、检测几何冲突并生成求解步骤。求解从可行布局出发，尽量保留当前布局，再根据冲突数安排移动次序。`game.js` 负责渲染、输入、动画和进度记录。GitHub Pages 使用 `main` 分支根目录。
