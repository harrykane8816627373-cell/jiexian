# 解线 · Untangle

一款空间益智小游戏。拖动红色节点，把虚线理成实线。

[在线试玩](https://jiexian.pagelet.host/)

## 玩法

- **随机出题** — 选择简单、中等或困难，节点数可自定为 4–36。节点分布在棋盘内外，混合题每局都有固定点，星盘内圈可以有多个同轨节点。同样设置下，各机制的数量和起始状态会重新抽取。
- **自定义题** — 摆点、连线，然后用「机制」工具配置联动组、星盘、共享滑轨、固定点和禁行区。先摆成无冲突的布局，再用「打乱题目」生成带已知解的题。点击「求解这题」会先尝试只修补少量冲突节点。纯禁行区题还可以在可用空间中放置整张平面图。全局判定会检查平行轨道的沿轨顺序及机构的活动范围，必要时启动精确非线性求解。
- **接着编辑** — 试玩或求解后可以编辑当前布局，也可返回原题。节点在三个视图中的显示大小一致。
- **辅助解题与计时** — 提示演示一步，一键求解优先拉开节点和连线，便于观察。首次移动自动开始计时，也可以手动开始、暂停或继续。任何时候都可以单独清零计时。解开后停表，仍可继续拖动或撤销。

拖动空白处移动视图，用双指捏合、滚轮或棋盘上的按钮缩放，按 1 回正。手机全屏时，竖屏棋盘会纵向展开，出题、计时和编辑功能可从「操作」打开。求解动画可暂停、继续，动画期间也可移动和缩放视图。用键盘时，先聚焦棋盘，用 Q / E 选点，按方向键移动，按住 Shift 可以增大步幅。

解题和编辑都支持撤销与前进。用 Ctrl / ⌘ + Z 撤销，用 Ctrl + Y 或 Ctrl / ⌘ + Shift + Z 恢复撤销的操作。

## 本地运行

直接用现代浏览器打开 `index.html` 可试玩和使用快速求解。要使用自定义题的全局判定，可在项目目录运行 `python -m http.server 8000`，然后访问 [本地棋盘](http://localhost:8000/)。GitHub Pages 等静态托管可以直接运行全局判定，无需安装前端依赖。当前随机题和自定义题草稿保存在当前浏览器。

全局求解的约束推导、完备性证明及测试命令见[自定义题的全局求解](./SOLVER.md)。

`engine.js` 计算节点位置、检测几何冲突并编排求解步骤。`puzzles.js` 生成可解的随机布局，并从 `planarity.js` 取得自定义题的平面嵌入。`game.js` 负责渲染、输入、计时和存档。平面性检测与增广的部分实现改编自 [NetworkX 3.5](https://github.com/networkx/networkx/tree/networkx-3.5)，许可见 [NETWORKX-LICENSE.txt](./NETWORKX-LICENSE.txt)。GitHub Pages 使用 `main` 分支根目录。
