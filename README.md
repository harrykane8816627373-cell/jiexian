# 解线 · Untangle

一款空间益智小游戏。拖动红色节点，把虚线理成实线。

[在线试玩](https://jiexian.pagelet.host/)

## 玩法

- **随机出题** — 选择简单、中等或困难，节点数可自定为 4–24。可玩多组独立的反向联动、每盘多点的旋转星盘、每轨多点的共享滑轨，也可挑战混合机制。
- **自定义题** — 摆点、连线，然后用「机制」工具配置联动组、星盘、共享滑轨、固定点和禁行区。先摆成无冲突的布局，再用「打乱题目」生成带已知解的题。自定义机制的求解器会在这些约束下搜索。
- **接着编辑** — 试玩或求解后可以编辑当前布局，也可返回原题。节点在三个视图中的显示大小一致。
- **辅助解题与计时** — 提示演示一步，一键求解展示整套动作。首次移动自动开始计时，也可以手动开始、暂停或继续。解开后停表，重开时归零。暂停和解开后都可以继续拖动或撤销。

拖动空白处移动视图，用滚轮或棋盘上的按钮缩放，按 1 回正。棋盘右上角的全屏按钮会放大工作区，并保留操作按钮。用键盘时，先聚焦棋盘，用 Q / E 选点，按方向键移动，按住 Shift 可以增大步幅。

## 本地运行

直接用现代浏览器打开 `index.html`。项目是原生 HTML、CSS 和 JavaScript，无需安装依赖。当前随机题和自定义题草稿保存在当前浏览器。

`engine.js` 计算节点位置、检测几何冲突并编排求解步骤。`puzzles.js` 生成可解的随机布局，并从 `planarity.js` 取得自定义题的平面嵌入。`game.js` 负责渲染、输入、计时和存档。平面性检测与增广的部分实现改编自 [NetworkX 3.5](https://github.com/networkx/networkx/tree/networkx-3.5)，许可见 [NETWORKX-LICENSE.txt](./NETWORKX-LICENSE.txt)。GitHub Pages 使用 `main` 分支根目录。
